# Figures

Save publication-ready figures and the exact plotting data used to create them.

## Required figures

1. Verdict-flip rate by recovery condition
2. Recovery gain by method and condition
3. Method by condition heatmap
4. Initial metric versus recovery scatterplots
5. Low-versus-high relearning slope chart
6. Recovery-versus-utility scatterplot
7. Mixed-prompt order comparison
8. Threshold-sensitivity heatmap
9. Metric agreement matrix
10. Per-checkpoint recovery profile

## Figure requirements

Every figure must include:

- figure number
- descriptive title
- labeled axes
- metric units or definition
- legend where needed
- sample size
- uncertainty where appropriate
- concise caption

Export final figures as PNG at 300 DPI. Also save SVG or PDF versions for the paper when practical.
